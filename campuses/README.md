# Campuses

The Crossing has four campuses: **Chesterfield (CFD)**, **Fenton (FEN)**, **Grant's Trail (GRT)**, and **Mid Rivers (MID)**.

If campus-specific lockups or marks exist (e.g. a campus name locked up with the master logo), add them here — one subfolder per campus code — and register them in `brand-kit.json`. If campuses simply use the master logo, this folder can stay as documentation only.
